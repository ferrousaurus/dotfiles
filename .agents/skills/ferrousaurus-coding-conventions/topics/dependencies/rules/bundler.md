## Bundler

### Go-To

- **Vite 8** — Fast HMR, native ESM development, excellent plugin ecosystem, and first-class support from TanStack Start. Vite 8 brings improved performance and stability over prior versions.

### Acceptable

None.

### Unacceptable

- **Vite ≤7** — Older Vite versions lack the performance improvements, bug fixes, and feature set of Vite 8. Always use the latest major version.
- **Webpack** — Slow builds, complex configuration, and outdated module bundling compared to Vite. Webpack's plugin model and configuration complexity are not justified when Vite provides a superior developer experience.
